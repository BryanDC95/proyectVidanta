Vidanta — Sitio web

Descripción

Proyecto de desarrollo web enfocado en la presentación de servicios y experiencias de Vidanta. Este sitio forma parte de mi portafolio personal para demostrar mis habilidades en desarrollo frontend.

Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript

Características

* Estructura de página desarrollada con HTML.
* Estilos y presentación visual con CSS.
* Funcionalidades e interacciones implementadas con JavaScript.
* Recursos gráficos organizados en una carpeta de imágenes.

Estructura del proyecto

* index.html: estructura principal del sitio.
* css/: hojas de estilo.
* IMG/: imágenes y recursos gráficos.
* script.js: funcionalidades JavaScript.

Objetivo

Practicar y demostrar habilidades de desarrollo frontend, organización de archivos y construcción de interfaces web.
